# Prompt 6: Monday automation

`/automation` starts fresh every run, with no memory of the last one. Put everything it needs in the instruction. Runs can start up to 15 minutes late. Each past run is saved.

```
/automation Every Monday at 8am, [your time zone]: [check folder X / look at my calendar for this week / pull last week's numbers from file Z]. Read last week's report in reports/ first so you can compare. Summarize what changed in 5 bullets, flag anything that needs me today, and save the report to reports/[date].md. Ask me only before reading new folders.
```
